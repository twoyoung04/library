# 我的藏书 iOS

公众版重做方案见 [产品与实施路线图](docs/rebuild-plan.md)。

原生 SwiftUI 客户端。最低 iOS 17，需要完整 Xcode。

1. 安装 Xcode 和 [XcodeGen](https://github.com/yonaskolb/XcodeGen)。
2. 在 `ios` 目录运行 `xcodegen generate`，打开生成的 `MyLibrary.xcodeproj`。
3. 在 Xcode 中将 Bundle Identifier 改为自己的标识，并选择签名团队。
4. 运行 App 后直接进入本机书库。首次录入可以扫码或手动填写。相机权限只在打开扫描器时请求。

## 本地书库和云同步

- 录入、搜索、编辑和删除先在本机完成。书库及待同步操作一起写入 Application Support 下受系统保护的文件。
- 从「设置 → 登录并开启云同步」使用现有 Django 账号。可以在登录时选择将游客藏书加入账号。原本的游客书库独立保留，退出账号后可继续使用。
- 账号书库连接 `https://wuminglib.site`。联网后上传待同步操作，再取回云端书库。遇到同时编辑产生的冲突，在设置中选择处理方式。
- 设置中的「自动同步」可随时暂停，暂停时仍可编辑账号的本机书库。也可从「书库备份」将藏书导出为 JSON 文件，再导入到另一台设备。
- 用现有 `wuming` 账号登录可以恢复原有藏书。同步依赖后端已部署的移动书库接口。
- 扫描器支持手电筒、照片识别、手动录入、连续扫描和撤销最近一次录入。断网时仍可保存书名或 ISBN。
