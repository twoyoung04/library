# 我的藏书 iOS 重做方案

**状态**　实施方案。已确认的方向是重做 iOS 界面，免注册使用本地书库，登录后可选云同步。

## 产品范围

首发面向在中国大陆整理个人和家庭实体藏书的 iPhone 用户。首次打开直接进入书库。扫码、手动录入、搜索、筛选、编辑、删除和文件导出在本机完成。需要换机恢复或多设备同步时，用户可以主动创建账号并开启同步，产品不要求绑定手机号。公开书评、社区和聊天留待后续评估。

首发登录方式建议采用邮箱验证码，是否增设 Apple 登录在账号阶段决定。注册前准备邮箱送达测试、重发限制和换机登录流程。App 内提供账号删除，以及清楚标明上传范围和同步状态的设置入口。

[设计与交互规格](experience-design.md)定义视觉体系、页面和验收场景。[数据与同步规格](data-sync.md)定义本地书库、账号隔离、同步与迁移。

## 当前系统与改造起点

当前 iOS App 通过登录进入书库，使用 `UserDefaults` 保存书单缓存和待同步录入。Django 提供 ISBN 查询和移动接口，图书副本、标签和书单查询沿用单人书库结构。新版从本地持久化与新的导航结构起步。ISBN 校验、书目查询和相机识别中经过验证的逻辑可以复用。对公众开放注册前，网页、移动 API 和后台数据任务涉及的私有数据都须有明确的归属和授权边界。

## 实施阶段

| 阶段 | 交付物 | 验收条件 |
| --- | --- | --- |
| 1. 产品与视觉原型 | 可点击的高保真原型，覆盖书库、搜索、扫描、确认与详情、同步设置。交付字号、颜色、间距和组件状态 | 演示首次录书、连续录书、找书和换机恢复四条路径，明确无网与权限拒绝时的替代入口 |
| 2. 本地 App | 新版 SwiftUI 界面、本地数据库、相机和照片识别、本地搜索、导出与恢复 | 飞行模式下完成录入、搜索、编辑和导出，强制退出再打开后数据完整 |
| 3. 云端隔离 | 私有书库模型、账户归属迁移、独立的新版接口、旧客户端兼容方案 | 双账号从网页和 API 验证列表、搜索、详情、导出、编辑和删除的隔离，旧书库迁移演练通过 |
| 4. 可选同步 | 邮箱账号、增量同步、游客数据导入、换机恢复、退出与删除账号 | 两台设备验证弱网、断网重试、并行修改、删除传播和重新登录，核对记录数及关键字段 |
| 5. 发布 | 独立测试环境、TestFlight 真机验收、生产迁移与回退预案、隐私说明和国内发布材料 | 通过设计走查、相机实测、备份恢复演练和备案核对，再开放注册 |

先用同一批中文书目和封面完成原型与本地版。云端接口可以并行设计，前提是书目与私有副本的标识、同步版本和删除规则已经约定。视觉实现从本地 App 阶段开始，测试阶段按原型复核所有状态。

## 发布前核对

- 用脱敏或合成书库测试。迁移演练核对版本、实体副本、标签、备注和存放位置，确认旧库归属后再操作生产数据。
- 云端账本及备份继续部署在国内。准备隐私政策，标明书库上传范围、账号数据以及删除和备份保留方式。向境内用户提供联网服务时，按实际发布主体和产品形态核对 App 备案。[工信部 App 备案通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)
- 上架版本核对隐私政策入口和账号删除流程。允许用户在 App 内创建账号时，提供 App 内账号删除入口。[Apple App 审核指南](https://developer.apple.com/app-store/review/guidelines/)
