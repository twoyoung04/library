# iOS 产品体验与视觉规格

## 信息架构

书库是启动页。首页显示藏书、搜索和录入入口，设置通过工具栏进入。搜索先查本机，列表上滑时固定在顶部。录入入口在首页、空状态和浏览书库时都容易触达。同步入口放在设置，首次录入的成功反馈仅确认这册书已保存。

## 视觉体系

采用当代图书馆目录的排版。新版重新定义配色、字体、组件和图标。浅色以暖白衬托封面和密集文字，深色使用独立的背景和分隔色。朱红用于录入、选中和少量强调。阅读状态、错误和同步结果同时使用文字或图标表达。

标题使用适合中文的宋体风格，正文、日期和控件采用可随系统字号变化的字体。页面依靠留白、对齐和细分隔线建立层次。封面比例稳定，缺图时显示低对比度占位，图片加载完成后保持行高。原型应同时展示中文长书名、多册藏书、无封面和高密度列表。

## 主要流程

| 场景 | 交互 | 需要设计的状态 |
| --- | --- | --- |
| 首次打开 | 直接进入空书库。主入口扫码，旁边提供手动录入和文件导入 | 空书库、相机权限未请求、权限被拒绝 |
| 单本录入 | 识别后显示轻触感反馈，展示待确认的书目。位置可选，确认后立即写入本机 | 已有同 ISBN、资料未查到、查询超时、只有 ISBN、977 期刊手动确认期号 |
| 连续录入 | 用户主动开启连续模式。沿用本次选定的位置，保留近期记录、计数和撤销入口 | 同码停留、同 ISBN 的第二册、撤销最近一册、相机中断 |
| 找书与查看 | 输入后即时查本地书库。支持按标签、位置和状态筛选。详情分列书目与实际副本 | 无结果、筛选生效、长标题、同版本多个位置 |
| 开启同步 | 登录后确认将本机书库并入账号。显示进度、失败原因与恢复入口 | 本机有数据、云端有数据、同步暂停、退出、换机恢复 |

手动和照片录入始终可达。飞行模式下仍可识别条码并保存 ISBN，书目补全在联网后可再次触发。相机权限仅在用户进入扫码时请求。

## 设计交付与验收

原型交付主要页面的亮色、深色和关键状态。设计稿标明滚动位置、焦点切换、键盘行为、相机权限、音效或触感的触发时机。正式实现随系统动态字体调整，支持旁白和减少动态效果，并为高频控件保留足够触控范围。

真机验收应覆盖连续扫码、低光和反光封面、大字号下的长书名，以及书库规模为数千册时的搜索和滚动。连续录入时，画面里持续出现的相同条码只能记入一次。用户可以通过明确的重新扫描动作录入同 ISBN 的另一本实体书。
